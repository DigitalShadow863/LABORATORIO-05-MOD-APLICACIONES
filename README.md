## Descripción
Este repositorio contiene los artefactos de modelado conceptual correspondientes al Laboratorio N° 5. El proyecto modela la estructura estática y el comportamiento dinámico de un **Sistema de Gestión Hotelera**, aplicando principios de alta cohesión, bajo acoplamiento, organización por paquetes y trazabilidad completa de requisitos funcionales (`RF-01` a `RF-05`).
